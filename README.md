# Teacher Companion for Schoology

Sets the due time of new assignments to 8:25 a.m., or to the time chosen in the extension's options.

1. Install [just](https://just.systems/man/en/)
2. `just build`
3. Load the `extension` directory at `chrome://extensions` using "Load unpacked"

Alternatively, you can manually run the commands from the [justfile](justfile).
