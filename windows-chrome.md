# Teacher Companion for Schoology

To install in Google Chrome on Microsoft Windows:

1. Download the [zip file](https://github.com/jeffs/schext/releases/download/v0.1.0/schoology-companion.zip).
2. Unzip the file: Right click the file and choose **Extract All**.
3. Move the new folder (`schoology-companion`) to your `Documents` folder.
4. Open new Chrome tab, and paste this into its location bar:
   ```
   chrome://extensions
   ```
5. In the top right corner of that page, switch **Developer mode** on.  
6. Near the top left corner, click **Load unpacked**.
7. Navigate to your `Documents` folder, single-click `schoology-companion`, and click the **Select** button.
8. Reload any open Schoology tabs.

To make sure the extension is working for you: Create a new assignment, then verify that its Due Time is 8:25 a.m.
